# 讲话与PPT伴随动作

近期五组约20秒PPT动作的节奏和相位已经收入 `assets/designs/ppt_natural20/`。这些是设计资料，不是默认机器人已通过检查的正式回放包。`catalog.json` 列名称、时长、模板和源HDF5哈希；各编号JSON保留手臂语义段、视线段及手指时序。NPZ内 `t` 为秒，`q` 为逻辑关节度数，`column_names` 给出46列的确切关节名；顺序为左臂6、右臂6、颈部2、左手16、右手16。各手顺序也可与独立profile内的源 `motion.json` 核对，不能靠位置猜。

源机器是可选profile `new_robot_192_168_2_27`，不是默认 `192.168.8.30`。源轨迹输入保存在该profile的 `trajectory_inputs/`，只用于核对设计。其原始数据没有当前默认模型的有效验证证明。迁移时先读 [方向、零位与限位](alignment-and-limits.md)；不能把源包的绝对手型和驱动方向直接复制到默认机器。相对小动作围绕当前参考重建；明确的示屏目标依据FK/视线重新适配。导出的新草稿依然需要完整检查、画面审阅和发布。

## 可选：参考真人动作视频

设计自然讲话、PPT讲解或不熟悉的手势时，可以建议参考真人视频；用户未提供时，也可自行寻找语境接近的公开视频或重看已有参考。优先看相邻短语怎样准备、抬起、展开、收低和承接，同时观察掌面、肘高、手指与视线的先后。不要只截取一个好看的终点姿态。

记录来源、实际查看的时间段/采样时刻、观察到的动作及本次采用的设计点。镜头切换、倍速或缺少连续画面时，不据此推断真实速度。真人参考用于理解语义和节奏，不直接照搬绝对关节角度；仍按机器人结构、当前参考与限位重建。没有合适视频或网络不可用时，说明未取得参考，继续用正侧面和手部仿真画面迭代，不将推测写成视频观察。

## 可选：用缓慢移动替代部分停顿

当讲话动作显得“抬手—停很久—放下”时，可把不承担明确语义的长停留改为朝下一个目标的缓慢、平滑移动。例如抬到胸前后缓慢外展、转动前臂或调整掌面，再自然收低；抬起可以较利落，展开和承接稍慢，不必全程匀速。使用共享速度/加速度的经过点，避免每个中间关键点都刹停。

这是改善连续表达的选项，不要求一直动：强调、等候、明确展示和用户指定的保持段仍可停留；方向反转时自然减速也合理。不用持续乱晃来填满时间。固定总时长时重新分配运动段与留白，检查实际速度和画面，不能仅把静止帧换成一串极小随机偏移。

## 可选：双臂承接，提前准备下一短语

在允许双臂参与的自然讲话中，可以让一侧主讲、另一侧较低位轻抬准备；主手收低时向外平滑经过，对侧同时抬起承接。比如右手较大幅度抬起时左手轻抬，右手降到较低位置再向外滑动，左手随后成为主手。手型在抬臂过程中逐步形成，头部跟随主要示意侧，不机械地同时转向两侧。连续短语之间可保留中低位准备姿态，不必每次双手回初始位后重启；整包首尾仍遵守参考要求。

把这种配合明确写入 `intent` 和两侧时间轴，控制主从幅度和重叠时段；无需每次换边，也不追求镜像齐摆。它不是给所有单臂动作自动添加对侧小动作的理由：用户要求对侧安静或另一侧未参与时，继续保持对应空流/已声明的参考保持。通用组件拼接器不会自动生成这种连续交接；需要时直接编排完整双臂tracks或自定义连续轨迹，并检查重叠期间的整段碰撞。

## 自然程度的判断

- 高低手势混合，示屏时可以高举，铺垫时保持低位。头部既可平视转头，也可小幅俯仰，不在每次抬手时仰头。
- 用不等长段落和留白表达；避免一直循环、左右严格轮流或在20秒内均分动作。双手可以短暂协同，随后由单手接续。
- 手型包括先稍张再弯、先弯再松和轻半握；ABD控制张开间距，MCP/PIP控制弯曲，拇指适量参与。不能仅让四指同步弯曲。
- 小幅错峰可让屈伸更自然：食/中/无名/小指依次延迟约0/40/80/120ms，拇指约100ms；ABD仍协调变化。它是设计选项，不是所有动作固定套用的时间表。
- 视线可略先于示意手转动，再回到观众；看手时让抬臂和低头部分重叠。最后以整段视频判断速度、停顿、掌心和手腕方向，而不是看到数值通过就接受。

## 可重用手型短语

`scripts/conversational_hands.py` 提供相对当前参考的 `rest/open/curl/soft/broad/relaxed` 和五组历史时序。通用 `motion.py create` 已支持设计JSON的 `hand_phrases`，可与双臂、颈部tracks组合，或只生成单手动作：

```json
{
  "package": "fb_phrase_example_v1",
  "name": "右手先轻张再放松弯曲",
  "duration_s": 6,
  "hand_phrases": [{
    "side": "right", "start_s": 0.5,
    "keys": [
      {"t_s": 0, "shape": "rest"},
      {"t_s": 1.3, "shape": "open", "amount": 0.3},
      {"t_s": 3.0, "shape": "soft", "amount": 0.3},
      {"t_s": 5.0, "shape": "rest"}
    ]
  }]
}
```

`keys.t_s` 是短语内相对秒数；同一手短语按时间排序且不重叠，首尾rest，末段后留至少0.12秒用于错峰收尾。每只手只能选普通track或短语之一。只有参与手建立流，另一只手保持空流。`amount` 缩放相对偏移，不保证放大后可用；旧基准接近ROM边界时必须降低幅度或改具名关节的形状。短语是C2五次包络，输入不合法直接拒绝；自动限速延长时元数据相位也随时钟缩放。

这里的张开/弯曲偏移是候选设计，不是标定或实体安全结论。参考手型改变后，即使首尾仍能回到新参考，中间也可能碰撞。重新检查完整轨迹，观察双手细节，必要时修改形状和幅度，不裁剪、扩大限位或借用另一机器的历史通过结果。
